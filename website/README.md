# Novyra News Web Edition

Fast, verified multi-source news platform designed for offline resilience and fast first load.

## Features
- **Fast First Load**: Instant article loading from pre-warmed cache.
- **Offline Reading & Bookmarks**: Full offline storage via browser `localStorage`.
- **Text-to-Speech (TTS)**: Built-in audio article reader powered by the Web Speech API.
- **Location Edition Filter**: Switch between Global (World), National, State, and Local editions.
- **Category Filter & Instant Search**: Dynamic filtering across Breaking, Tech, Business, Politics, Health, Science, and Sports.
- **Dark / Light Mode**: Smooth theme toggle with preference persistence.

## How to Run
Simply open `index.html` in any web browser (Chrome, Edge, Firefox, Safari) or host on any static web host (GitHub Pages, Netlify, Vercel, Firebase Hosting, Apache/Nginx).
